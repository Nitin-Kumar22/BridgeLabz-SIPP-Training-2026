# 📂 Repository Structure

This repository is organized topic-wise to make learning and revision easier. Each folder contains Java programs, practice questions, scenario-based problems, and coding exercises related to that topic.

| 📂 Folder | 📖 Description |
|-----------|----------------|
| 📁 Arrays | Array fundamentals, traversal, searching, sorting, rotation, prefix sum, and array-based interview problems. |
| 📁 Strings | String manipulation, character arrays, pattern matching, palindrome, anagrams, and common string algorithms. |
| 📁 Recursion | Basic to advanced recursion problems, backtracking concepts, recursive tree visualization, and interview questions. |
| 📁 Exception_Handling | Java exception handling, try-catch-finally, throw, throws, custom exceptions, and exception-based programs. |
| 📁 OOP | Object-Oriented Programming concepts including classes, objects, inheritance, polymorphism, abstraction, encapsulation, and interfaces. |
| 📁 Collections | Java Collections Framework including ArrayList, LinkedList, HashSet, TreeSet, HashMap, PriorityQueue, Stack, Queue, and Iterators. |
| 📁 LinkedList | Singly, doubly, circular linked lists and interview problems like reverse, middle node, cycle detection, merge, etc. |
| 📁 Stack | Stack implementation, balanced parentheses, postfix/prefix evaluation, monotonic stack, and interview questions. |
| 📁 Queue | Queue, Circular Queue, Deque, Priority Queue, BFS applications, and queue-based interview problems. |
| 📁 Sliding_Window | Fixed-size and variable-size sliding window techniques with optimized interview problems. |
| 📁 Hashing | HashMap, HashSet, Frequency Map, Prefix Sum + HashMap, Two Sum, Duplicate Detection, and hashing-based interview problems. |
| 📁 Heap | Min Heap, Max Heap, Heapify, Heap Sort, Priority Queue, Top-K Elements, and heap interview questions. |
| 📁 Tree | Binary Tree traversals (Inorder, Preorder, Postorder, Level Order), Height, Diameter, BFS, DFS, recursion, and interview problems. |
| 📁 BST | Binary Search Tree operations including Search, Insert, Delete, Validation, Successor/Predecessor, and interview questions. |
| 📁 DBMS | ER Model, Normalization, Keys, Constraints, Transactions, ACID Properties, and DBMS interview questions. |
| 📁 SQL | SQL queries including SELECT, WHERE, GROUP BY, HAVING, ORDER BY, Joins, Subqueries, Aggregate Functions, Views, Indexes, and practice questions. |
| 📁 JavaScenarioBased | Real-world Java scenario-based coding questions for interview preparation. |
| 📁 Practice_Problems | Daily coding questions, assignments, company interview problems, and LeetCode-style practice. |
